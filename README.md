# The Sukoon Lab — website package

Static, responsive website intended for GitHub Pages. Upload the contents of `sukoonlab_site` to the repository root (or replace the existing files), then commit and push.

## Catalogue update (October 22, 2026)
The Music catalogue includes the first 30 songs transcribed from the Spotify for Artists screenshots supplied by the artist. Each entry has a Spotify search link and a YouTube search link so the controls lead to a useful destination even where an individual public track URL has not yet been verified. Exact known links are used where available. These are search destinations, not claims that every direct track URL has been verified.

Some poetry credits are marked “to be confirmed” rather than risking a false attribution. Please replace those with the release metadata once confirmed. Some other poet attributions are best-effort and marked for verification.

## Files
- `index.html` — page structure and sections
- `styles.css` — responsive styling
- `app.js` — catalogue rendering and search/filter interaction
- `catalogue.js` — 30 music catalogue entries and platform destinations
- `assets/` — artwork assets already included in the prior package

## Important
The catalogue reuses available artwork from the earlier package as visual placeholders; not every card image is the matching release cover. Swap in the corresponding release artwork when available. No fabricated per-track Spotify IDs are used.
