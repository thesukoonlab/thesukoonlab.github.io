Poetry excerpt performed in this rendition

The original release description contains these verses from Allama Iqbal's poem. This is the text supplied for the rendition, not a claim that the complete poem is reproduced here.

Tere ishq ki inteha chahta hoon
Miri saadgi dekh kya chahta hoon

Sitam ho ki ho wada-e-be-hijabi
Koi baat sabr-aazma chahta hoon

Ye jannat mubarak rahe zahidon ko
Ki main aap ka samna chahta hoon

Poetry: Allama Iqbal. Musical arrangement, performance and sound recording: The Sukoon Lab.
